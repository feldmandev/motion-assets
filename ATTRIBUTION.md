# Asset provenance and licenses

This is a mixed-license collection. Publishing these files does not transfer
trademark rights or turn vendor artwork into MIT-licensed artwork.

| Module | Source / terms |
| --- | --- |
| Tools, adapters, gallery shell | Original Motion code, MIT; see `LICENSE`. |
| Material Symbols | Google, Apache-2.0. Font, codepoints and license are fetched from the same recorded upstream commit. See `assets/symbols/upstream.json` and `LICENSES/Apache-2.0.txt`. |
| Fonts | Feldman Font, Google Sans Flex and Fredoka, SIL Open Font License 1.1. Original notices and font metadata are retained in `assets/fonts/OFL.txt`. |
| Shapes | Existing Motion shape SVG exports. Source and provenance are retained in `assets/shapes/NOTICE.md`; no independent license grant for upstream designs is inferred. |
| Device icons | Mixed original drawings, derivatives and vendor-app extractions, with source notes retained in `assets/devices/provenance/`. Vendor artwork and logos remain subject to their original rights. No blanket open-source license is asserted for those assets. |
| Device 3D models | Procedurally generated estimates, not CAD scans or vendor extractions. Source/reference information is recorded per model; device brands and marks belong to their respective owners. |

The gallery's model-viewer bundle retains its upstream license headers. It is
used to display models and is not part of Motion's original code license.

Consumer packages include these notices. Consumers should retain the applicable
notices when redistributing assets. The module catalogs identify origin and
estimated/provisional status; they do not claim vendor endorsement.
