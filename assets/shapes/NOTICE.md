# Shape exports

Imported from the existing Motion `motion-shapes/original` and `1024` collections.
The SVGs are Material-style shape exports, with their original geometry retained.
No private project data or source-repository history is included.

The catalog provides stable IDs, view boxes and SVG paths. Platform animation
implementations can continue to use their native rounded-polygon types; the
shared exports do not replace those implementations with raster images.

The source collection did not include an asset-specific license declaration.
Its upstream designs are not relicensed by the repository's MIT code license.
